# AI Chatbot Pro

A professional chatbot built using

- LangGraph
- SQLite Memory
- Gemini
- Streamlit

## Features

- Persistent Memory
- Resume Conversations
- Streaming Responses
- Conversation Titles
- Thread Metadata
- Statistics
- Token Counter
- Conversation Summaries
- Export Chat
- Beautiful Sidebar

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
